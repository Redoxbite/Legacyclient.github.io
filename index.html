Protection

GitHub edge, static origin

This site is a static GitHub Pages build. There is no app server to flood. Traffic is absorbed by GitHub’s global CDN, TLS, and DDoS mitigation.

Active

GitHub Pages CDN

Pages are served from GitHub’s edge network. Large floods hit the CDN, not a home origin.

Active

HTTPS only

Forced TLS, strict referrer policy, and a locked-down Content Security Policy on every page.

Active

Static attack surface

No database, no login, no API. Contact is rate-limited in the browser before a mail client opens.
